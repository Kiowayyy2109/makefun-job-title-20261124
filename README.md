Entry for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty ($5 in USDC).
One job title, 60 characters at most: **Senior Vice President of Apologizing to Geese**
(45 characters). A senior corporate title doing the lowest, most absurd job —
apologizing to geese — so the twist lands on the first read and the person doing
it is instantly picturable.

## Run it

```sh
python3 main.py
```

Writes the job title to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`
when the variable is unset). Python 3 standard library only, no network,
deterministic: two runs produce byte-identical output.
